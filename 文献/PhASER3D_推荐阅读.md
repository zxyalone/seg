# 对当前模型分割能力有帮助的论文

2026-10-15 整理。依据：`/Users/alone/Desktop/paper` 中的计划文档（§11 修改记录）、`results/实验结果汇总.md`，以及 `manuscript/论文_中文_EAAI初稿.md` 第 6–7 节。论文路径均相对本目录。

## 先说结论：选论文的依据

当前方法已经不是相位模块，而是 nnU-Net（VoComni 预训练）+ DCA（按目标 CNR 衰减病灶对比度）+ CFC（对比度不变特征一致性）。你自己的实验已经说明了几件事：

- 结构模块没有提高低 CNR 召回：A6−A1 差 +0.25 pp；E11 把相位全部置零，召回不变。
- 提升来自训练样本：测试集低 CNR 召回 +9.1 pp，MSD08 外部验证 +7.7 pp。

所以下面只推荐针对现有短板、并且能直接落到训练样本或训练目标上的论文。`03_相位一致性与频域`、`09_频域小波与相位_顶会`、`08_边界与形状` 和 `12_3D骨干与对比基线` 里的大多数论文，留作相关工作引用即可，不建议再投入实验。

## 短板 1：高 CNR 小病灶召回下降（68.5% → 60.9%）

这是论文里明确承认的代价（第 7.2 节），审稿人最可能追问。

| 优先级 | 论文 | 能帮什么 |
|---|---|---|
| **P0** | `06_小病灶与病灶检测/2020_Shirokikh_LossReweighting-LesionSize_MICCAI.pdf` | 按病灶大小的倒数给损失加权，专门提高小病灶检出。它比 CC-DiceCE 温和：CC-DiceCE 的高 CNR 小病灶召回是 83.7%，但每例假阳性达 4.00。可以作为 DCA+CFC 的附加损失，只补小病灶。 |
| **P0** | `07_肿瘤合成与标注稀缺/2024_Lai_Pixel2Cancer_MICCAI.pdf`（已引用） | 你的数据里，Pixel2Cancer 是唯一没有这个代价的增强（高 CNR 小病灶 69.9%，肿瘤 Dice 75.2%），而 DCA+CFC 补的是低 CNR。两者作用的病灶层不重叠，"DCA+CFC + Pixel2Cancer" 是最直接的组合实验。 |
| P1 | `04_评测与数据集/2023_Kofler_BlobLoss_IPMI.pdf`、`06_小病灶与病灶检测/2023_Chen_AdaptiveRegionLoss_TPAMI.pdf` | 实例级 / 区域自适应损失，可作为第一项的替代方案。 |
| P1 | `07_肿瘤合成与标注稀缺/2024_Chen_DiffTumor_CVPR.pdf`、`2023_Hu_LabelFree-LiverTumor_CVPR.pdf` | 都专门讨论了小肿瘤合成及其检出敏感度，可借鉴其中按大小控制合成的做法。 |

还有一个设计上的想法（不是现成论文）：只对等效直径 ≥ 10 mm 的病灶做 DCA 衰减，或者按 d′ = CNR·√N 而不是只按 CNR 抽目标。注意，探针 P2（√N 叙事）没有通过，所以这只是一个待检验的假设。

## 短板 2：外部数据假阳性增加（MSD08 上每例 +0.77）

新增的假阳性主要是肝内、直径 < 10 mm 的低对比度小区域（+0.73），F1 因此低于对照。

| 优先级 | 论文 | 能帮什么 |
|---|---|---|
| **P0** | `06_小病灶与病灶检测/2021_Cai_LesionHarvester_TMI.pdf` | 困难负样本挖掘 + hard negative suppression loss。思路是把模型在训练集上产生的肝内小假阳性挖出来，作为负样本再训练，正好对应"DCA 让网络对微弱信号更敏感，副作用是多报"。 |
| **P0** | `05_肝肿瘤专题/2023_Yan_PLAN-PixelLesionPatient_MICCAI.pdf` | 肝肿瘤专用：在像素分割之上加病灶级分类和病人级聚合，用病灶级判断过滤假阳性。可以替代固定的 4 mm 连通域阈值。 |
| P1 | `06_小病灶与病灶检测/2021_Baumgartner_nnDetection_MICCAI.pdf` | 和 nnU-Net 同一框架的检测版本，给每个连通域一个置信分数，按分数过滤，而不是只按大小。 |
| P1 | `11_基础模型与预训练/2024_Li_AbdomenAtlas_MedIA.pdf`、`2024_Ma_FLARE22_LancetDH.pdf` | 提供大量无肿瘤的肝脏 CT，可作为纯负样本加进训练，压低肝内误报。要先核查与 LiTS 的病例重叠（对应计划中的 E17）。 |
| P2 | `13_评测不确定性与校准/2020_Mehrtash_CalibrationUncertainty_TMI.pdf` | 用连通域级不确定性过滤误报。但你的 §4b 诊断显示漏检不是校准问题，所以这项只对假阳性端有意义。 |

## 短板 3：CFC 的独立贡献不确定，在 SegResNet 上训练崩塌

现状：CFC 在测试集上 +3.2 pp，验证集上 −3.4 pp。在 SegResNet 上，余弦损失使特征幅值失控，训练崩塌。

| 优先级 | 论文 | 能帮什么 |
|---|---|---|
| **P0** | `10_频谱域泛化与跨中心/2021_Xu_FACT_CVPR.pdf` | 和 CFC 同构：原图与增强图之间的一致性约束（co-teacher regularization），但教师用的是**动量（EMA）教师**，约束的是**预测**而不只是特征。你目前用同一网络做无梯度前向当教师。改成 EMA 教师，并在 softmax 输出上加一致性，可能同时解决稳定性问题和"只约束方向、不约束幅值"的问题。 |
| **P0** | `10_频谱域泛化与跨中心/2023_Ouyang_CausalityDG_TMI.pdf` | GIN 全局强度非线性增强 + 一致性约束，是"强度扰动增强 + 一致性"在医学分割上最接近 DCA+CFC 的前作。相关工作里必须正面区分；它的 GIN 也可以和 DCA 叠加，用来提高跨中心稳健性。 |
| P1 | `07_肿瘤合成与标注稀缺/2019_Yu_UA-MT-SemiSup_MICCAI.pdf` | EMA 教师 + 不确定性掩膜。可以把 CFC 的"病灶膨胀 6 体素"区域改成按教师不确定性加权。 |
| P2 | `07_肿瘤合成与标注稀缺/2023_Bai_BCP-SemiSup_CVPR.pdf` | 双向复制粘贴 + 一致性，与病灶级增强（你已引用的 TumorCP）是同一脉。 |

## 短板 4：增益依赖预训练（从头训练 100 epoch 只有 +2.2 pp，CI 跨 0）

| 优先级 | 论文 | 能帮什么 |
|---|---|---|
| **P0** | `11_基础模型与预训练/2024_Li_SuPreM_ICLR.pdf` | 在 AbdomenAtlas 上做有监督预训练，迁移效果优于自监督。换一种预训练权重再跑 DCA+CFC，能把"依赖预训练"从 VoComni 的特例推广成一般结论，也可能直接提升绝对性能。同样要核查与 LiTS 的数据重叠。 |
| P1 | `11_基础模型与预训练/2023_Ulrich_MultiTalent_MICCAI.pdf`、`2023_Liu_CLIP-UniversalModel_ICCV.pdf` | 多数据集联合训练，覆盖肝肿瘤，可作为另一类强初始化。 |
| P1 | `02_基线与预训练骨干/2023_Roy_MedNeXt_MICCAI.pdf`（原有） | 在 TriALS 架构里，MedNeXt-L 的低 CNR 召回最高（64.5%），而且它的块内带 GroupNorm，不会出现 SegResNet 那种 CFC 幅值失控。如果要补一个架构迁移的正结果，选它比 SegResNet 合适。 |

## 短板 5：大而淡的病灶只分割出局部（肿瘤 Dice 没有提升：74.0 对 74.6）

| 优先级 | 论文 | 能帮什么 |
|---|---|---|
| P1 | `05_肝肿瘤专题/2021_Zhang_MultiPhase-UncertainInpainting_MICCAI.pdf` | 对不确定区域做二次补全（inpainting），针对的就是"检出了，但范围不全"。 |
| P1 | `07_肿瘤合成与标注稀缺/2025_Chen_ScalingTumorSeg_ICCV.pdf`、`2025_Wu_FreeTumor_NatComm.pdf` | 用大规模合成数据扩展训练分布。FreeTumor 公开模型的训练数据包含 LiTS，你的论文已注明，需要重训才能公平比较。 |

## 不建议再投入实验的方向

- **相位、频域、小波**（03、09）：E11 与 A7 已经否定了相位对召回的作用，只保留作机制分析和相关工作。
- **边界损失**（08）：肿瘤 HD95 / ASSD 与对照的差值区间都含 0，瓶颈在检出，不在边界。
- **更换骨干**（12）：同一训练条件下，结构差异小于预训练和训练长度的影响（论文第 6.9 节已有结论）。

## 建议的实验顺序

1. DCA+CFC + Pixel2Cancer 组合（短板 1）。代码已有，成本最低。
2. CFC 改为 EMA 教师 + 输出一致性（短板 3）。参照 FACT，同时检验能否修复 SegResNet 上的崩塌。
3. 困难负样本挖掘，或加入健康肝 CT 作负样本（短板 2）。参照 Lesion Harvester。

这三项都在冻结协议之后，只能作描述性报告，或者作为下一篇工作。
