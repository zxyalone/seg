# 解码端病灶检出计划：深层特征的病灶级检出与检出引导解码

2026-10-15 制定。**本文件在 D0 探针运行之前提交**。§3 的探针判据、§4–§5 的继续条件以提交时间为准，看到结果后不得修改；确需修改时，在 §9 追加记录，写明日期、原因和改动，原判据保留。

前置：`docs/频域模块计划.md`（两个频域网络模块的探针均为 NO-GO，§10 有完整记录）。按用户决定（2026-10-15），新外部数据集暂不准备，本计划的全部结果只作描述性报告。

## 0 一句话

F0 v2 探针显示，A13b 编码器深层特征能把病灶（包括分割输出完全漏掉的病灶）与肝实质区分开，问题可能出在解码和判定。本计划先用 D0 探针检验一个可落地的版本：在冻结的 A13b 深层特征上训练一个轻量检出头，在整卷上能否找回 A13b 漏检的病灶，并且明显优于直接降低分割阈值，同时假阳性可接受。通过才实现检出引导解码（D1），不通过就停止。

## 1 依据

### 1.1 支持这一方向的证据

| 证据 | 数据 | 来源 |
|---|---|---|
| 深层特征可分 | MSD08，位置匹配负样本：第 3 层 AUC 中位数 1.000（低 CNR < 10 mm）、0.988（低 CNR > 20 mm） | `results/freq_probe_v2/msd08/` |
| 分割输出却漏掉 | 同一批病灶的块内覆盖率：A0 低 CNR < 10 mm 为 0，A13b 0.151；A13b 低 CNR > 20 mm 0.523 | 同上 |
| 不是校准问题 | A0 漏检低 CNR 病灶内 p_tumor 第 90 百分位中位数 0.001，肝脏概率 0.99；放宽阈值几乎不增加召回 | `results/missed_probability/` |
| 两类漏检 | A0 漏检低 CNR 病灶（≥ 50 体素）中 19 / 39 个病灶内有体素 p ≥ 0.5（"部分点亮"、范围太小未匹配），其余基本未点亮 | 同上 |

### 1.2 需要检验的弱点

- **负样本太干净。** v2 的负样本取自远处肝实质最深处，环境均匀；真实假阳性出在肝边缘、裂隙、血管旁和病灶附近（MSD08 上 A13b 新增假阳性主要是肝内 < 10 mm 的低对比度区域，`results/external_msd08/fp_analysis/`）。深层 AUC ≈ 1 可能部分来自环境差异。
- **可分 ≠ 可检出。** 线性可分是病灶体素对比负样本体素的统计量；检出需要在整卷上定位，并控制每例假阳性。
- 因此 D0 用**全部肝实质**做负样本，在**整卷**上数假阳性，并以"降低分割阈值"作为必须超过的基线。

### 1.3 不重复的设计

| 已有设计 | 区别 |
|---|---|
| Small-Tumor Head（`SmallTumorDetailHead`） | 浅层特征（e0、e1）、体素级二分类辅助损失，只在训练时用；E11 置零其先验无影响。本计划用深层特征，做病灶级目标，并在推理时参与解码 |
| A9 / PFCR / A1 门控 | 在跳连上调制特征，目标是低 CNR；本计划在解码端注入检出证据 |
| A12 CC-DiceCE（文献基线） | 逐连通域损失，测试集召回最高（82.2%），但 FP/scan 4.00；作为 D1 的比较对象 |

## 3 Step D0：冻结特征的检出探针（事先登记）

### 3.1 模型、特征与队列

- **模型：** A13b seed 0、1、2，checkpoint_final，冻结，推理精度与训练末验证相同（AMP）。
- **整卷滑窗：** 块 128³、步长 0.5、高斯加权、无 TTA，与 nnU-Net 推理相同。每个块同时取：
  1. 分割 logits；
  2. 编码器第 3 层（1/8 分辨率，256 通道）与第 4 层（1/16，320 通道，最近邻上采样到 1/8）特征，拼接为 576 通道；
  3. 描述性对照：第 1 层（1/2，64 通道）平均池化到 1/8。

  各块的特征按同一高斯权重在 1/8 网格上加权平均。
- **训练队列：** LiTS fold 0 训练集 83 例（与检出头在 D1 中的训练数据相同）。
- **判据队列：** MSD08 303 例（参照肝来自 A0 多数投票）。
- **描述性队列：** LiTS fold 0 验证集 21 例。

### 3.2 检出头

- 1/8 网格上的 L2 逻辑回归（与 F0 相同：按训练数据标准化，正负等权，λ = 1e-2），每个 seed 各训练一个。
- **正样本：** 肿瘤占比 ≥ 0.5 的格子；某病灶（≥ 50 体素）没有这样的格子时，取它占比最大的格子。每个病灶最多 64 个。
- **负样本：** 肝实质占比 ≥ 0.5、肿瘤占比为 0 的格子，包括病灶附近和肝边缘。每例随机取最多 2000 个，随机种子按病例名固定。
- 在训练集上拟合，不调超参数，直接用于 MSD08。

### 3.3 检出、匹配与基线

（2026-10-15 修订，在任何 D0 代码运行之前，见 §9：全部匹配与计数改在原始图像网格上进行。）

- **A13b 的分割与漏检：** 用 nnU-Net 的滑窗推理得到 logits，按 nnU-Net 导出流程还原到原始网格（与 `missed_lesion_probability.py` 相同，该流程已逐病灶复现 eval_val）。之后 argmax，去掉等效直径 < 4 mm 的连通域，26 连通，IoU > 0.1 一对一匹配；病灶、CNR 与分层全部调用 `evaluate.py`，与冻结协议一致。
- **检出头概率图回到原始网格：** 1/8 网格的概率每格复制为 8³ 体素（最近邻），去掉滑窗填充，再按 nnU-Net 导出概率的重采样、去裁剪和转置路径映射到原始网格。滑窗块的起点按 round(起点 / 8) 落到格子上（nnU-Net 的块起点不一定是 8 的倍数，误差 < 1 格）。
- **检出头的检出：** 在参照肝（标签 > 0）外扩 6 mm 的范围内，头部概率 > t 的体素取 26 连通域，t ∈ {0.95, 0.9, 0.8, 0.7, 0.6, 0.5, 0.4, 0.3, 0.2, 0.1}。
- **完整性核对：** 每个 seed 的低 CNR 召回与全部召回，与归档的 `results/external_msd08/tables/lesions_pp4mm.csv`（低 CNR 79.0 / 77.8 / 78.4）之差都须 ≤ 2 个百分点。不满足则先查明原因，不进入判定。
- **找回：** A13b 漏检的病灶，体积 ≥ 30.4 mm³（相当于计划网格上 50 个体素），如果与检出头的某个连通域有体素重叠，记为被找回。
- **新增假阳性：** 检出头的连通域，与任何金标准肿瘤体素和 A13b 预测肿瘤体素（4 mm 后处理后）都不重叠者。按例计数。
- **阈值基线：** 同一次推理的 A13b p_tumor > t'（t' ∈ {0.5, 0.4, 0.3, 0.2, 0.1, 0.05}，4 mm 后处理）。漏检病灶在新阈值下与某个预测连通域 IoU > 0.1 匹配，记为找回；新增假阳性 = 该阈值下每例未匹配的预测连通域数 − argmax 下的数目。

### 3.4 判据

- **工作点：** 对每个 seed，分别取新增假阳性 ≤ 0.5 个 / 例的最低阈值（头部 t*、基线 t'*）。0.5 与 §4b 的预算相同。
- **R_head：** t* 下被找回的 A13b 漏检病灶比例（全部 CNR）。**R_thr：** t'* 下的同一比例。均先在每个 seed 上计算，再取 3 个 seed 的平均。
- **GO（全部满足）：**
  1. R_head ≥ 0.25；
  2. R_head − R_thr ≥ 0.10，按病例 bootstrap（2000 次，种子 0；每次重采样病例后重新计算两个比例）95% CI 下限 > 0。

  工作点按 seed 固定，bootstrap 中不重新选阈值。
- **NO-GO：** 其余情况，停止，不实现 D1，按 §7 处理。
- **描述性：** 低 CNR 漏检病灶的找回率；按"部分点亮 / 未点亮"（漏检病灶内 A13b 是否有 p_tumor ≥ 0.5 的体素）分层的找回率；新增假阳性 ≤ 1.0 个 / 例时的 R_head 与 R_thr；第 1 层对照头的 R；LiTS 验证集的同样指标。

### 3.5 成本

- 训练集 83 例与 MSD08 303 例各做一次整卷滑窗，3 个 seed。CPU 预处理是瓶颈，三卡 6 分片预计 1.5–2 小时。
- 训练集只保存采样后的特征（约 0.6 GB）；MSD08 只保存 1/8 网格的头部概率图与逐病灶、逐例的统计（< 1 GB）。磁盘余量约 17 GB。

## 4 Step D1：检出引导解码（D0 GO 后才实现）

### 4.1 结构

- **检出头：** 编码器第 3 层与上采样的第 4 层拼接后，经 1×1×1 卷积得到 1/8 分辨率的病灶热图 h（sigmoid）。
- **注入：** 最细的两个解码 stage 的输出各加一条零初始化的残差支路 x ← x + W_s·up(h)（W_s 为 1 → C_s 的 1×1×1 卷积）；肿瘤 logit 加 β·logit(up(h))，β 初始化为 0。初始化时网络输出与 A13b 完全相同，VoComni 权重加载不受影响。
- **检出损失：** 对 h 用 focal loss（γ = 2），目标与 §3.2 相同（病灶格子为正、肝实质格子为负，其余忽略），权重 1，沿用 V2 的辅助损失升温。
- **训练设置：** 与 A13b 相同（DCA + CFC、200 epoch、fold 0、同一 VoComni 权重），新组记为 **D13b**。

### 4.2 pilot（seed 0）

- **评估：** MSD08 303 例（判据）与 LiTS 验证集（描述）。冻结协议的指标与 4 mm 后处理。
- **继续条件（全部满足，相对 A13b_s0）：**
  - 全部病灶召回 ≥ +3 个百分点（544 个病灶中多检出约 16 个）；
  - FP/scan ≤ +0.3；
  - 逐病例肿瘤 Dice 不低于 −1.0 个百分点。

  不满足就停止，不调参重试。

### 4.3 多 seed 与消融

- pilot 通过后补 seed 1、2。复现条件：3 个 seed 均值相对 A13b 的 3 个 seed 均值满足 §4.2 的条件，且至少 2 个 seed 单独满足。
- 复现后加一个消融组 **D13b-aux**（只有检出头与损失，不注入解码器，3 个 seed），用来区分"多任务改善了表征"与"检出证据引导了解码"。
- A12（CC-DiceCE）与 A14（Pixel2Cancer）的已有结果作为描述性比较。

## 7 风险与退路

| 风险 | 应对 |
|---|---|
| D0 NO-GO：检出头找回的病灶不比降低阈值多 | 说明深层特征的可分性主要来自环境差异，或者分割头已经用尽了可用信息；写进机制分析，停止解码端模块。退路为计划 `docs/频域模块计划.md` §8 的训练侧方法，需另立计划 |
| D0 的完整性核对不通过 | 先修正滑窗或匹配实现，在 §9 记录，不进入判定 |
| D1 增加假阳性 | §4.2 的 FP/scan 条件约束；检出头本身的负样本已包含病灶附近与肝边缘 |
| 检出头在训练集上过拟合（编码器特征已记住训练病灶） | 检出头只有线性参数；D0 在未见过的 MSD08 上评估，正好检验这一点 |
