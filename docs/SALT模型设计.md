# 新模型设计：SALT（谱尺度空间锚定的病灶 Transformer）

2026-10-16 制定。**本文件在 G0 与任何训练运行之前提交。** §3 的 G0 判据、§4 的 pilot 继续条件和 §5 的选择规则以提交时间为准，看到结果后不得修改；确需修改时，在 §11 追加记录，写明日期、原因和改动，原判据保留。

按用户要求（2026-10-16），本模型**完全不使用 DCA 与 CFC**：所有 SALT 组的配置里 `PHASER_LCA` 不出现，训练样本只用 nnU-Net 的默认增强。

## 0 一句话

把肝肿瘤分割从"逐体素分类"改成"**逐病灶的集合预测**"：在 VoComni 预训练的 nnU-Net 上加一个病灶查询解码器。每个查询预测一个病灶的掩膜和一个病灶级置信度，查询的初始位置与尺度由**傅里叶域尺度空间**给出；解码器的特征融合换成**自适应低通 / 高通滤波**；判定病灶与血管、肝包膜时用掩膜**功率谱的二阶矩**描述其形状。三处频域知识各对应一个实测的失败模式（§1.2）。

```
CT 图块 ─► VoComni PlainConvUNet 编码器 ─► nnU-Net 解码器（FAF-3D：自适应低通 / 高通融合）─► 语义头（背景 / 肝 / 肿瘤）
                                                │ 1/8、1/4、1/2 分辨率特征           │ 全分辨率像素嵌入
                                                ▼                                    ▼
   SSA：语义肿瘤概率与 CT 的傅里叶域尺度归一化 LoG 组 ─► 中心 + 半径锚点 ─► 病灶查询解码器（掩膜交叉注意力 × 6 层）
                                                                              │
                                                     每个查询：掩膜 m_q ＋ 置信度 s_q（输入含 SMD 形状谱矩）
                                                                              ▼
                       推理：P(v) = max_q s_q·σ(m_q(v))，与语义肿瘤概率在前景内融合（w = 0.5）
```

### 1.2 SALT 针对的三个失败模式

| 失败模式 | 证据 | SALT 的对策 |
|---|---|---|
| **病灶级判定**：困难负样本（血管断面、肝包膜、裂隙、实质不均）与小病灶在体素级不可分 | D0；MSD08 新增假阳性多为"肝边缘、裂隙附近或均匀实质中的数毫米小区域"（`results/external_msd08/fp_analysis/`）；A0 在 MSD08 每例 3.36 个假阳性、病灶 F1 43.8 | 病灶查询解码器（LQD）：在病灶级做判定，每个候选有置信度；SMD 把"团块 / 管 / 片"的形状差异显式交给判定头 |
| **部分点亮的漏检**：语义头有微弱响应但低于 0.5 | D0 的 A13b 漏检中，部分点亮 98 个、未点亮 128 个（3 个 seed 合计） | SSA：在语义概率上做尺度空间极值检测，不依赖 0.5 阈值，弱响应的团块也能成为候选；CT 上的极值补充未点亮的候选 |
| **病灶内部分割不全** | A0 测试集肿瘤 RVD −12.4%（预测体积系统偏小），大而淡的病灶检出后分割不全 | FAF-3D：上采样的深层特征先经自适应低通，减少病灶内部的特征突变（类内不一致）；集合预测本身输出整块掩膜 |

边界不是瓶颈：肿瘤 HD95 / ASSD 与对照的差值区间都含 0（`results/boundary_metrics/`）。所以 SALT 没有像 HFF-Net、E²Net、FASS 那样以边界增强为主线。

## 2 方法

代码：`nnUNet/nnunetv2/training/nnUNetTrainer/phaser/lesion_query.py`（SSA、LQD、SMD、匹配与损失、融合）、`phaser/freq_fusion3d.py`（FAF-3D）、`phaser/unet.py`（接入）、`nnUNetTrainer_phaser.py`（开关、优化器分组、损失）。开关全关时网络与 A0 完全相同。

### 2.1 SSA：谱尺度空间锚点

对证据图 v（体素网格，间距 (s_z, s_y, s_x) mm），在傅里叶域计算尺度归一化的 LoG 响应：

  R_σ = F⁻¹[ F(v) · (2πσ|f|)² · exp(−2π²σ²|f|²) ] = −σ²∇²(G_σ ∗ v)，|f|² = f_z² + f_y² + f_x²（cycles/mm）

- 频率按物理单位取，所以各向异性的体素间距被精确处理（与 scipy 逐轴实现的差 < 2e-6，`experiments/test_salt.py`）；四周补零 3σ_max 防止循环卷积串扰。
- 半径组 r ∈ {2.5, 4, 6, 9, 13.5, 20} mm，σ = r/√3（3D LoG 的零交叉在 √3σ，实测半径 4 / 9 mm 的球分别选出 3.8 / 8.7 mm）。
- 在 3×3×3 空间邻域和相邻尺度上取极大值，按响应排序，中心距离小于两者较大半径的较弱峰被抑制。
- 两个证据源，各取至多 16 个锚点：
  1. **语义**：语义头的肿瘤概率（响应 > 0.02）。阈值无关，部分点亮的病灶也能成为候选。
  2. **图像**：预测前景（肝 + 肿瘤概率 > 0.5，过小则用体部）内标准化的 CT，取 |R|（低密度与高密度两种极性），只在前景内取峰。它覆盖语义头完全没看到的病灶，同时把血管断面、包膜等困难负样本送进判定头。
- 每个锚点 = (中心, 半径, 响应, 来源)。不足的槽位保留为空锚点（只有来源嵌入）。锚点不回传梯度。

### 2.2 LQD：病灶查询解码器

- **查询**：16 个语义锚点 + 16 个图像锚点 + 8 个自由查询（Q1 消融为 32 个自由查询）。锚点查询的内容 = 最细记忆层在中心处的特征（三线性采样）+ 来源嵌入 + 尺度 / 响应的 MLP；位置 = 中心的 3D 正弦编码经 MLP。
- **记忆**：解码器 1/8、1/4、1/2 分辨率三层特征（128³ 图块中为 16³、32³、64³），1×1×1 投影到 128 维，加层嵌入和 3D 正弦位置编码。
- **层**：6 层（三个尺度轮流两遍），每层 = 掩膜交叉注意力 → 查询自注意力 → FFN（512），后归一化，4 头，float32。掩膜交叉注意力只看当前预测掩膜（σ ≥ 0.5）内的位置；锚点查询另外总能看到中心 2r 球内的位置；掩膜为空时看全部。
- **头**：每层输出病灶置信度 z_q 与掩膜嵌入 e_q；掩膜 m_q(v) = e_q · φ(v)，φ 是全分辨率解码特征的 1×1×1 投影（32 维）。

### 2.3 FAF-3D：频率感知解码融合

在解码器 1/8、1/4、1/2 三个阶段，转置卷积上采样后、与跳连拼接前：

  up′ = up + α·(ALPF(up) − up)，skip′ = skip + β·(skip − LPF_h(skip))

ALPF / LPF_h 是由两路输入（各压缩到 32 通道）逐体素预测的 k³ 核（softmax，非负且和为 1，即低通）；1/8、1/4 阶段 k = 5，1/2 阶段 k = 3，高通核 k = 3。α、β 零初始化（不做权重衰减），核生成器近均匀初始化，所以初始化时网络与预训练解码器逐元素相同。实现为 k³ 个平移视图的加权和，不展开 unfold 张量，显存 O(|x|)。

### 2.4 SMD：谱矩形状描述子

对每个查询在 1/2 分辨率上的软掩膜 M，计算功率谱的二阶矩张量：

  T = Σ_f f fᵀ |M̂(f)|² / Σ_f |M̂(f)|² = (1/4π²) Σ_v ∇M ∇Mᵀ / Σ_v M²（Parseval）

特征值 λ₁ ≥ λ₂ ≥ λ₃ 给出 [log(λ₁+λ₂+λ₃), λ₂/λ₁, λ₃/λ₁, log(1+体积)]：团块的频谱各向同性（≈ 1, 1），管状结构的能量在一个平面上（≈ 1, 0），片状结构的能量在一条线上（≈ 0, 0）（`test_salt.py` 实测 ball 1.00/0.93、tube 1.00/0.00、sheet 0.00/0.00）。描述子不回传梯度，经零初始化的 MLP 加到置信度头的输入上。

### 2.5 训练目标

- 语义头：nnU-Net 的 DiceCE + 深监督，与 A0 完全相同。
- 查询：病灶实例 = 肿瘤标签的 26 连通域（≥ 20 体素）。每层做匈牙利匹配，代价 = 2·(−σ(z)) + 5·BCE + 5·Dice（Mask2Former 的权重），在采样点上计算：4096 个均匀点 + 每个病灶（外扩 3 体素）512 个点。损失 = 2·加权 BCE（无目标权重 0.1）+ 5·BCE + 5·Dice（按病灶数归一），7 个预测（初始 + 6 层）取平均。
- 总损失 = DiceCE + 0.2·ψ(e)·L_query，ψ 为与 V2 相同的 5 epoch 升温。
- 优化：沿用 A0 的 SGD 与分组学习率；查询解码器单独一组，学习率 ×4（2e-2），前 10 个 epoch 线性升温（3D TransUNet 用 SGD 0.08 加升温）。FAF-3D 在 1.0× 组。200 epoch、fold 0、同一 VoComni 权重、AMP、checkpoint_final，与 A0 相同。

### 2.6 推理

- 病灶图 P(v) = max_q σ(z_q)·σ(m_q(v))（取最大而不是累加，低置信度的查询不会堆积成假阳性）。
- 融合：p_t′ = w·p_t + (1 − w)·P·(p_l + p_t)，肝 = 前景其余部分，背景不变；**w = 0.5 在此登记，不在验证集上调**。滑窗推理、无 TTA、4 mm 后处理照冻结协议。
- 内置消融：同一个训练好的模型，w = 1 即其语义头（`test_salt.py` 验证与语义头逐元素相同），w = 0 只用查询。w ∈ {0, 0.5, 1} 的结果只作描述性报告。

### 2.7 成本

参数（实测，6 stage 网络）：查询解码器 1.75 M（隐藏 128 维、6 层），FAF-3D 0.34 M，合计为骨干（31.20 M）的 6.7%。显存：64³ 层交叉注意力（2 × 4 头 × 40 查询 × 262 144 位置）是大头，估计在 A0 之上增加 2–4 GiB，以预检实测为准（§3.1）。SSA 每步两次 6 尺度 FFT，GPU 上为毫秒级（CPU 上 2 × 128³ 约 4 s）。

### 3.2 G0：锚点能否覆盖 A0 的漏检（只决定 SSA 是否保留）

- **模型与数据**：A0_s0（无 SALT 模块）；MSD08 303 例（判据）、LiTS 验证集 21 例（描述）。
- **做法**（`experiments/analysis/salt_anchor_probe.py`，预处理空间）：A0 滑窗 softmax；病灶 = 肿瘤 26 连通域（≥ 20 体素）；A0 检出 = 与 4 mm 后处理后的某个预测连通域 IoU > 0.1；漏检中最大肿瘤概率 ≥ 0.1 记为部分点亮，否则未点亮。在 nnU-Net 的每个 128³ 滑窗位置（步长 0.5）按网络里的同一函数计算 16 + 16 个锚点；某锚点中心落在病灶外扩 2 体素内、且半径在病灶等效半径的 [1/3, 3] 倍内，即算覆盖。对照：每个窗口同样数量的锚点放在随机前景位置、随机半径（种子 0）。
- **判据（MSD08）**：**GO**：A0 漏检病灶的覆盖率 ≥ 50%，且 ≥ 2 × 随机锚点的覆盖率，且 A0 已检出病灶的覆盖率 ≥ 90%。否则 **NO-GO**：SSA 去掉，Q2–Q4 改为 32 个自由查询（在 §11 记录），其余组件照常。
- 描述：按 A0 状态（检出 / 部分点亮 / 未点亮）、大小、CNR 分层的覆盖率；语义锚点与图像锚点各自的贡献。

| **Q3** | Q2 + SMD | 谱矩形状描述子 |
| **Q4 = SALT** | Q3 + FAF-3D | 完整模型 |
| **F1** | 只加 FAF-3D | 频率感知融合单独的作用 |

- 运行：`tmux new -d -s pilot-Q4 'GPU=0 experiments/server_salt_pilot.sh Q4 0'`。顺序固定：先 Q4、Q1、F1（三张卡并行，约 1 天）；Q4 通过后再训练 Q2、Q3（论文的逐项消融）。
- **继续条件（MSD08，相对 A0_s0，冻结协议的 4 mm 指标，`experiments/analysis/salt_pilot.py`）**：

| 组 | 收益（全部） | 护栏（全部） |
|---|---|---|
| Q1–Q4 | 病灶 F1 ≥ +3.0 个百分点 **或** FP/scan ≤ −0.5；**且** 逐病例肿瘤 Dice ≥ +1.0 个百分点 | 全部召回 ≥ −2.0；低 CNR 召回 ≥ −3.0 |
| F1 | 逐病例肿瘤 Dice ≥ +1.0 个百分点 | 病灶 F1 ≥ −2.0；全部召回 ≥ −2.0 |

- 不满足就停止，不调参重试。pilot 只作进入 / 停止决定，不作论文证据。LiTS 验证集 21 例（训练末验证）只描述。

## 5 Step T2：多 seed 复现与最终模型

- 通过 pilot 的组补 seed 1、2。**复现条件**：3 个 seed 的均值相对 A0 的 3 个 seed 均值满足 §4 的同一组条件，且至少 2 个 seed 单独满足。
- **最终模型的选择顺序（固定）**：Q4 → Q3 → Q2 → Q1，取第一个复现的组。F1 只作为 FAF-3D 的单独消融报告。都不复现：病灶级集合预测在 83 例训练集上不成立，照实报告，作为阴性结果写进论文。
- 复现的组在 LiTS 测试集 27 例上做一次描述性评估，与 A0、A1、A13b 等已有结果并列；新增病灶级 FROC（以查询置信度为病灶得分）。

## 6 Step T3：冲击 SOTA 的评测（用户确认后另行登记细节）

内部 fold 0 的 27 例测试已被确认性使用过，MSD08 在本计划中是开发数据。要写"超过 SOTA"，至少需要下面一条，建议都做：

1. **LiTS 官方 70 例测试集**：用全部 131 例做 5 折，5 个模型集成，提交 LiTS CodaLab（入口是否仍开放需先核实），报告逐病例与全局 Dice。只有这一条能与文献中的 SOTA 直接比较（LiTS 论文报告的历届最佳逐病例肿瘤 Dice 为 0.674 / 0.702 / 0.739）。
2. **同一流程下重训的强基线**（MambaClinix 的做法）：nnU-Net（A0）、nnU-Net ResEnc-M、**3D TransUNet（语义查询，作为最接近的竞争方法）**、MedNeXt、SwinUNETR、U-Mamba；相同划分、预处理、4 mm 后处理与统计。
3. **新的独立外部集**：TCIA Colorectal-Liver-Metastases（约 197 例）与 HCC-TACE-Seg（105 例），推理前做独立性检查并冻结终点（主要：病灶 F1 与逐病例肿瘤 Dice；保持：低 CNR 召回），Holm 校正。用户 2026-10-15 决定暂缓外部集；**没有它，结论只能是描述性的。**

## 7 论文定位与诚实的预期

- 目标：Medical Image Analysis 或 IEEE TMI。
- 贡献（按结果取舍，不预设）：① 病灶级集合预测解决体素级读出无法区分困难负样本的问题（以 D0 的阴性结果为动机）；② 傅里叶域尺度空间锚点，把弱响应与未响应的病灶变成查询；③ 3D 频率感知融合与谱矩形状描述子；④ 一组事先登记的阴性结果（体素级频域模块无效）作为机制分析。
- 预期：最可能改善的是**病灶级 F1 与假阳性**（判定层的改动）以及**逐病例 Dice**（大病灶的完整性）。低 CNR 召回不是 SALT 的主要目标，护栏只要求不明显下降。在 83 例训练集上训练一个 Transformer 解码器有欠拟合风险（§8），这也是先做 pilot 的原因。新颖性论断（"首个……"）投稿前需重新做文献检索。

## 8 风险与退路

| 风险 | 应对 |
|---|---|
| 训练数据少（83 例、518 个病灶），查询解码器学不好 | 语义头与 A0 完全相同并参与融合，w = 0.5 时最差也接近语义头；Q1 与 w ∈ {0, 0.5, 1} 的描述性对比能分清是"查询学不好"还是"融合不当" |
| SGD 训练 Transformer 不稳 | 单独的学习率组与 10 epoch 升温；注意力用 float32；预检检查 50 步内损失有限、所有参数有梯度 |
| 显存超出 12 GB | §3.1 的固定缩减顺序 |
| 图像锚点被血管、包膜占满 | 这是设计意图（困难负样本进入判定）；G0 分别报告语义 / 图像锚点的覆盖率，若图像锚点无贡献，论文中照实说明 |
| MSD08 部分"假阳性"是未标注病灶 | F1 / FP 只作相对比较；最终证据靠 §6 的新外部集 |
| 外部泛化仍差 | 后续可在训练中加入频域域泛化增强（RAS4DG / FACT 的幅度谱扰动，`文献/10_…`），另立计划 |
