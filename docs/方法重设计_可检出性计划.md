## 2 假设与模块设计

### 2.1 为什么相位不行，可检出性可能行

- Rose 模型：在白噪声下，一块面积（体积）为 N、对比噪声比为 CNR 的病灶，其可检出性约为 d′ ≈ CNR·√N。对比度低的大病灶，把噪声在病灶范围内平均掉后仍可检出。
- 相位一致性是与尺度无关的比值，天然丢掉了 √N 这一项；Kovesi 阈值又是绝对量，CNR ≤ 1 时直接弃权（Step 2，4.8 节）。所以"与对比度无关"不等于"可检出"。
- 可检出性统计量保留"按噪声归一化"（与对比度缩放无关），同时随窗口体积积累证据。
- 真实肝脏里限制可检出性的未必是白噪声，而可能是肝实质本身的不均匀性；合成自检中只加 3 HU 的低频不均匀性，22 mm、ΔHU = −2.5 的病灶就对所有特征几乎不可分。真实数据中情况如何，正是探针要回答的问题。

### 2.2 候选模块 v0（探针通过后才实现）

> 2026-10-11 探针结果后按 §4 规则简化：去掉 Welch 方差归一化和纹理分支，只保留以肝实质为参照、带符号的多尺度中心-环带强度对比，见 §11。下文保留原设计以便对照。

在每个编码器跳连上，对特征的可学习单通道投影 p_l = wᵀX_l（与 PFCR 的代理相同）计算多尺度中心-环带统计：

- 中心高斯 σ_c、环带核 A = (G_s − kG_c)/(1 − k)，σ_s = 3σ_c，σ_c 按层初始化为与物理尺度 {1, 2, 4, 8, 16} mm 对应的值并可学习；
- d′_r = (μ_c − μ_a)/√(σ²_c/N_c + σ²_a/N_a)，纹理 v_r = ½·log(P_c/P_a)（高通残差功率比）；
- 统计在肝脏软掩膜内用归一化卷积计算，掩膜来自一个轻量肝脏头（肝脏 Dice 约 96%，任务容易）；每张图在掩膜内做稳健标准化，对应探针中的经验零分布；
- 门控与 A1 完全同形：X̃_l = X_l·(1 + tanh(γ_l)·σ(a·g + b))，γ 初始化为 0，g 为 d′ 与 v 的组合（多尺度取最大或可学习加权）。

与 A1 同形是刻意的：A1、PC 门控（A2）与新模块之间唯一的差别是门控信号，消融表可以直接比较"哪种证据有用"。参数和计算开销预计远小于 PFCR（无 FFT，只有可分离高斯卷积）。

v1（仅在 v0 的 pilot 不通过、且探针显示线索存在时考虑）：把 d′、v 图经零初始化的 1×1×1 卷积注入跳连，而不是做乘性门控。

- **队列：** fold 0 训练集 83 例的全部病灶（≥ 50 体素，约 518 个）。验证集和测试集不参与。
- **特征：** I（细尺度强度）、Ims（多尺度强度，只做面积积分）、D（可检出性 d′）、T（纹理）、DT = max(D, T)。全部在 GT 肝脏掩膜内计算，并用同病例远处肝实质做经验零分布标准化。用 GT 肝脏掩膜偏乐观，这一点在报告中注明；网络中改用预测掩膜。
- **主指标：** 每个病灶的 AUC_bg（病灶体素 vs 同病例距任何病灶 > 15 mm 的肝实质）和 hit（病灶内中位数 > 远处肝实质的 99% 分位数）。AUC_local（病灶 vs 病灶外 3–15 mm）只作参考，因为大尺度特征在边界附近会扩散。

**事先登记的预测**（脚本 `summarize()` 自动判定）：

| 编号 | 内容 | 判定条件 |
|---|---|---|
| P1 | 低 CNR 层中，D 比细尺度强度 I 更能把病灶从肝实质中区分出来 | AUC_bg 中位数 D ≥ I + 0.05，且病例级 bootstrap 95% CI 下限 > 0，且 hit 率 D > I |
| P2 | D 相对 I 的增益随病灶增大而增大（可检出性叙事） | 低 CNR 层内 Spearman(直径, AUC_bg(D) − AUC_bg(I)) 的 95% CI 下限 > 0 |
| P3 | 低 CNR 病灶存在纹理信号 | 低 CNR 层 AUC_bg(T) 中位数 ≥ 0.60 |
| P4 | 局部噪声归一化在面积积分之外还有贡献 | 低 CNR 层 AUC_bg 中位数 D ≥ Ims + 0.02 |

**判定规则：**
- P1 成立 → GO，实现 §2.2 的 v0（D + T）；
- P1 不成立但 P3 成立 → 只保留纹理分支，模块改名，叙事从"可检出性"改为"纹理异质性"；
- P1、P3 都不成立 → NO-GO。单期相 CT 的强度统计里没有足够信息，转入 §9 的退路。
- P2、P4 不决定是否继续，只决定论文叙事：P2 不成立就不讲 √N；P4 不成立就承认增益来自多尺度积分本身，模块简化为多尺度强度对比。

| A13b | A13a + **对比度不变的特征一致性**：同一网络对原图块做一次无梯度前向（教师），衰减图块的解码器特征（学生，有梯度）在被衰减病灶膨胀 6 体素的区域内向教师靠拢，损失为 1 − 余弦相似度，取最细的 2 个解码器尺度，权重 1，沿用 V2 升温 | §4b 诊断显示漏检是表示层面的失败，因此约束表示本身而非只约束输出 |

- **固定设置：** 两组的 p、目标分布、膨胀半径、尺度数和权重在此登记后不再改动；200 epoch、fold 0、同一 VoComni 权重。A13b 每步多一次无梯度前向，预计训练时间约为 A11 的 1.3–1.5 倍。
- **训练：** A13a、A13b 各 seed 0、1、2，与 §6 的 A11 seed 1、2 一起，共 8 次训练。
- **最终方法的选择规则**（事先固定的优先顺序，不是挑最好的）：
  - 依次检查 A13b → A13a → A11，第一个满足 §6 复现条件（相对 A1 的 3 seed 均值：低 CNR 召回 ≥ +5 个百分点、FP/scan ≤ +0.3、至少 2 个 seed 单独满足）的组就是论文的"本文方法"。
  - 三组都不满足 → 停止，按 §9 处理。
  - 验证集上组间差异只描述，不作为选择依据。
- **测试集：** A0、A1、A11、A13a、A13b 各 3 seed 和 A12_s0 全部一次性评估。确认性比较只有"本文方法 vs A1"（主要）和"本文方法 vs A0"（次要），做 Holm 校正；其余组作为消融，只做描述。
- **实现与测试：** `phaser/lowcnr.py`（`sample_target_cnr`、`lesion_contrast_augment(target_cnr=True, region_out=…)`、`contrast_consistency_loss`），开关 `PHASER_LCA_TARGET=cnr`、`PHASER_LCA_CONS_WEIGHT`、`PHASER_LCA_CONS_STAGES`。A11 的代码路径和随机数顺序不变。`experiments/test_lowcnr.py` 全部通过：
  - 目标抽样的 10/50/90 分位与表一致；
  - 合成病灶 CNR 2.5 / 2.0 被衰减到 0.31–1.27；
  - 已低于所有目标的病灶不变；
  - 一致性损失对相同或整体缩放的特征为 0，梯度只在区域内；
  - 在 PhaserUNet 中梯度能经最细解码器特征传到编码器。初始化时一致性损失约 0.009（合成数据、小网络），权重仍按登记取 1。
- `check_grads.py` 增加 A13b 一致性损失被调用且为正的检查。

## 7 Step 4：冻结与一次性测试

§6 复现条件满足后，先提交冻结协议（沿用 `PROTOCOL_FROZEN` 机制），再一次性评估 27 例内部测试集；外部队列的选择与独立性核查（E14、E17）照原计划进行。冻结内容事先登记如下：

- **组：** A0、A1、A11、A13a、A13b，各 3 个 seed（fold 0 的 checkpoint_final，推理设置与验证相同，无 TTA）。A12_s0 作为文献基线只做描述性报告，不做假设检验。"本文方法"按 §6c 的选择规则确定（2026-10-11 修订，见 §11）。
- **后处理：** 去掉等效直径 < 4 mm 的预测连通域，所有组相同，不再调整。
- **主要终点：** 低 CNR 层病灶召回（冻结三分位 1.2785 / 1.9208，IoU > 0.1 一对一匈牙利匹配，26 连通），每组取 3 个 seed 的均值。
- **主要比较：** 本文方法 vs A1；次要比较本文方法 vs A0；两者做 Holm 校正。其余组只做描述。
- **统计：** 按病例的配对 bootstrap（10000 次，重采样测试病例，每次对 3 个 seed 取均值）给出召回差的 95% CI。CI 跨 0 时只报告"未观察到显著差异"，不改写为趋势性结论。
- **次要终点：** FP/scan、逐病例肿瘤 Dice、病灶 F1、CNR × 大小分层召回、同等 FP/scan 下的低 CNR 召回。
- **局限（事先承认）：** 测试集只有 27 例，低 CNR 病灶数可能很少，统计功效有限；单折、无交叉验证。

## 8 论文叙事（BSPC 方法论文）

- **暂定题目：** Detectability-guided skip gating for low-contrast liver tumor segmentation in CT。
- **引言：** 低对比度是 LiTS 的常态（训练病灶 CNR 中位数 1.62），现有方法包括频域方法都没有针对它。
- **贡献：**
  1. 以 Rose 可检出性为依据的模块：按噪声归一化、随窗口体积积累证据，并带纹理分支；
  2. "与对比度无关不等于可检出"：相位一致性的机制分析和 PFCR 消融作为反例（现有 Step 2、A6、A7、E11 全部保留）；
  3. 门控信号对比：|∇f|、PC、可检出性在同一门控结构下比较；
  4. 按 CNR × 大小分层、带后处理基线、5 折交叉验证的评测。
- **新颖性边界：** 中心-周围对比门控已有类似工作（如 CHAM-Net，Information Sciences 2025），必须在相关工作中正面区分；投稿前在 Google Scholar 系统检索 Rose/detectability 与分割网络结合的工作。
