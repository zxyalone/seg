## 阶段 1：GPU 上的代码检查（约 1–1.5 小时）

服务器实测（2026-10-09）：RTX3080Ti 12GB；128³全精度检查OOM，按本清单回退96³/50步，A0–A8全部PASS。日志：`experiments/check_grads_gpu.log`。Copy2已保存预测复算及独立目录重新推理均4/4 PASS。

- [x] **GPU 版梯度检查**：
  ```bash
  PYTHONPATH=nnUNet $PY experiments/check_grads.py --patch 128 --steps 50 --device cuda \
    | tee experiments/check_grads_gpu.log
  ```
  - 合格标准：最后一行 `SUMMARY` 里 9 组都是 PASS。
  - 判定规则：`WARN` 不算失败，`FAIL` 才是（见 `experiments/README.md` §2）。
  - 这个检查不用 AMP，128³ 时可能显存不够。OOM 时改用 `--patch 96`。
- [x] **Copy2 复现回归**：V2 改动了模块代码，需要确认旧推理路径仍然一致。
  ```bash
  $PY reproduce_metrics.py             # 从已保存的预测复算，几秒钟，应 4/4 PASS
  $PY reproduce_metrics.py --predict   # 重新推理，40–60 分钟，可放到阶段 3 的间隙
  ```
  第二条会自动设置 `PHASER_LEGACY=1`，同样应该 PASS。不通过说明 legacy 开关没有完全还原旧行为，把输出发给我。
