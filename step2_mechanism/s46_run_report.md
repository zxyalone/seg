- 518 个病灶按病例和体素数与 s42 匹配；CNR 最大绝对差为 0，冻结阈值未修改。CSV 和 JSON 的分层计数、中位数、hit 率及判据一致。
- LiTS_046 的一个 192 体素病灶：Ims/D/T/DT 主 AUC 为 NaN。依原脚本，AUC 用 nanmedian，hit 记 False；没有事后改筛选规则。低 CNR 多尺度主 AUC 有效病灶为 172/173。
- 探针使用 GT 肝脏掩膜及 GT 病灶排除背景，较真实网络推理乐观；后续模块必须使用预测掩膜，不读取 GT。
- 两张 montage 已做显示检查；单张切片不足以确认或排除期相和标注问题。

## GPU 实现与核对

新增可选 `--device cuda:2`（CuPy 13.6.0），仅高斯滤波在 GPU，默认 CPU。E1–E3 GPU 自检通过。合成体最大 AUC 差 5.585e-6；首个训练病例 12 个病灶最大 AUC 差 2.018e-6，hit 及病灶属性完全一致。真实病例总耗时 26.48 → 23.57 秒（约 12% 加速）。因 CPU 全队列已运行约三分之一，正式结果沿用该 CPU 运行。
