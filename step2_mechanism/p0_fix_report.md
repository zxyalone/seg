## 0. 结论摘要

我按 `design_review.md` §5.1 的实现级清单动手改了 3 个"确定会污染结论"的问题，然后**逐项隔离验证**。
结果是：**3 个里只有 0 个被证明是改对了；2 个实测有害或不确定，已全部回退。**

| 编号 | 原判 | 实测判定 | 处理 |
|---|---|---|---|
| **I1** 噪声阈值 T 过激 → 加相对上限 κ·den | 我原以为这是主因 | **明确有害** | 默认 κ=0（回退），代码+文档保留为负结果 |
| **I2** `pc_max_voxels=2^20` 砍掉最浅层分辨率 → 提到 2^24 | 我以为纯属 bug | **证据矛盾** | 默认回退 2^20，作为可消融变量 |
| **I6** 频率网格 `d=1` 忽略真实 spacing → 用 plan spacing | 我以为纯属 bug | **无明确收益** | 默认关闭，作为单变量消融项 |
| **I3** 双重 sigmoid → `softmax(logits)[:,1]` | 语义错误 | **确认修复**（动态范围 ×6.4） | **保留** |
| **I4** Small-Head 监督迟至 epoch 60 → 提前到 0 | 时序错误 | 逻辑修复，效果待训练 | **保留** |
| **I8** 无随机种子 → `PHASER_SEED` | 缺失 | 无副作用 | **保留** |
| **I9** Focal Tversky α/β 硬编码 → 环境变量 | 缺消融开关 | 无副作用（默认不变） | **保留** |

**这条结果本身就是本次工作最有价值的部分**：它说明 `design_review.md` 里"实现级缺陷"的定性过于自信——T/den > 1 这个**机制描述**是对的，但由此推出的**修法**是错的。

## 2. I1 被否定：相对阈值破坏了算子唯一的定位机制

### 2.1 合成厚板

|---:|---:|---:|---:|---:|
| 0.5 | 0.522 / 3.5 | 0.500 / 1.2 | 0.500 / 1.3 | **0.387 / 0.9** |
| 1.0 | 0.672 / 39.9 | 0.500 / 1.5 | 0.500 / 1.8 | **0.291 / 0.8** |

| 8.0 | **1.000** / 10019.8 | 0.842 / 673.0 | 0.937 / 1900.1 | **0.424 / 1.0** |
| 16.0 | 1.000 / 5548.8 | 1.000 / 3347.4 | 1.000 / 6683.1 | 0.943 / 1.4 |

真实病例 patch（LiTS_006）：

| 变体 | T/den | PC 均值 | **PC>0 占比** | PC 边界 | PC 外周 | **边界/外周** |
|---|---:|---:|---:|---:|---:|---:|
| V0 原始 | 1.101 | 0.1889 | **47.8%** | 0.0105 | 0.0288 | 0.366 |
| V1 仅 I2 | 1.099 | 0.1396 | 39.5% | 0.0163 | 0.0265 | 0.616 |
| V2 I2+I6 | 1.175 | 0.1367 | 38.1% | 0.0080 | 0.0197 | 0.405 |
| **V3 +I1** | 0.473 | 0.3303 | **93.3%** | 0.2994 | 0.3078 | 0.973 |

### 2.2 为什么我的推理错了

我原来的论证是："T 是绝对量纲，对比度降时信号缩而噪声不缩，T/den > 1 → PC 恒为 0；所以把 T 压到 κ·den 就能恢复"。

机制描述没错（合成上 T/den 从 2.35 降到 0.47，PC 从恒 0 变成全域非零）。**错在把"PC 非零"当成了"PC 有用"。**

用 κ=0.999 直接探测 `num/den`（此时 `pc ≈ num/den − κ`）：

> **边缘 num/den ≈ 1.0029；内部 num/den ≈ 0.9992。**

对阶梯状目标，比值在边界和内部**几乎完全重叠**（差 0.4%）。也就是说：

> **`num/den` 这个比值本身不携带边缘信息。Kovesi 绝对阈值之所以"能检测边缘"，靠的是它在平坦区把 PC 压到 0 的**稀疏化**（弃权），而不是靠对比。**

所以任何"解开阈值"的操作都会把算子变成一个"处处非零但无处突出"的平滑场——AUC 掉到 0.25~0.42（**低于随机**，因为在平滑边缘上 PC 的峰并不落在 ±1.5 体素的壳层中心）。κ=0.5 使 PC>0 的体素从 47.8% 涨到 93.3%，定位能力随之消失。

### 2.3 这一条的推论（比结论本身更重要）

`design_review.md` 里我把 `T/den = 1.17–1.98` 列为 I1 缺陷，暗示"这是可以修的 bug"。实测说明它不是：

> **PC 的低 CNR 失效不是阈值调参问题，而是 `‖Σv_s‖/ΣA_s` 这个公式对阶梯状目标缺乏判别力所致。** 把标量 PC 当"稠密的空间路由依据"用，是这个用法错了，不是参数错了。

这直接支持了 C2/C1 判定，也说明为什么 gpt 的 CU-PFR（"语义不确定性 × 相位证据"的交互项）和 deepseek 的 PhASER-H（"病灶字典 vs 混淆结构字典"的判别式证据）都**不是**在阈值上做文章——它们换掉了证据形式。

## 3. I2 证据矛盾：cap 不只是成本控制，它同时在降噪

- **合成**：V0（cap 2²⁰，160³ 上降采样到 80³）AUC 在 CNR ≥ 2 全为 **1.000**；V1（cap 2²⁴，全分辨率）只有 0.50~0.52。**去掉 cap 明显变差。**
  原因合理：2× 平均把白噪声降 √8，噪声底降低 → 阈值下移 → 边缘通过而内部仍被压制。
- **真实**：V1 的边界/外周比 0.616 优于 V0 的 0.366。**去掉 cap 略好。**

两个证据方向相反，样本量都不足以定论（合成只用了一种几何；真实只有一个 patch，且该比值本身很弱——两者都远小于 1）。

**处理：默认保持 2²⁰ 不变**，但把"有效降采样因子"写进 `_last_diag`（`downsample_factor` / `work_shape`），让分辨率不再被静默改变；同时把 `PHASER_PC_MAX_VOXELS` 作为单变量消融项。

## 4. I6 无明确收益，改为消融项

| 对比 | 边界/外周比 |
|---|---:|
| V1（d=1） | 0.616 |
| V2（plan spacing） | 0.405 |

物理上各向异性校正（1.0 vs 0.779 mm，1.28×）是"更正确"的，但它同时把可学习 ρ 的单位从 cycles/voxel 换成 cycles/mm，等于把滤波器组整体缩放最多 1.28×——这是**行为改变**，不是纯 bug 修复。

**处理：默认关闭（`spacing=None` → d=1）**，保留 `PHASER_PC_SPACING=plan|<显式值>`。这样它成为 A 系列里可单变量测试的一项，而不会静默改变所有既有对比。

## 5. I3 确认有效，但附带一个必须记录的后果

同一组 small_head logits（Copy2 权重，epoch 49）下：

| prior 公式 | 取值范围 | 标准差 |
|---|---|---:|
| 旧 `sigmoid(sigmoid(z))` | [0.5098, 0.7304] | 0.0119 |
| 新 `softmax(z)[1]` | [0.0141, 0.9998] | **0.0756（×6.4）** |

修复确实恢复了 prior 的概率语义与动态范围。

⚠️ **后果：这会改变 router 的输入分布。** Copy2 的 router 是在旧缩放（0.51–0.73）上训练的，换成 (0.01, 1.00) 后**旧 checkpoint 的路由行为不再有效**。
含义：**A 系列的所有组必须使用同一版代码重训，不能拿旧 checkpoint 与新代码混比。**

（注：Copy2 的 Small-Head 本身在旧代码下从未被训练——旧代码把它推迟到 epoch 60，而 Copy2 是 epoch 48。所以它的 prior 判别力本来就是噪声。上面的 prior 数值只用于验证公式语义，不代表训练后效果。）

## 8. 修正后的行动建议

原计划是"修 I1–I4 → 跑 A0/A1/A5"。现在应改为：

1. **不再修 I1/I2/I6**（已证无益或不确定），而是把它们**作为 A 系列的消融变量**：
   - `PHASER_PC_NOISE_KAPPA=0.5`（预期：更差，可作为"阈值确实不是瓶颈"的对照）
   - `PHASER_PC_MAX_VOXELS=2^24`（cap 的作用需在真实指标上结清）
   - `PHASER_PC_SPACING=plan`（各向异性校正）
2. **必须重训全部组**（I3 使旧 checkpoint 与新代码不可比）。
3. **最小对照仍是 A0 / A1 / A6，并补 A5**（无 PC ranking）。
4. **Step 3 的假设方向应改**：既然 `num/den` 对阶梯目标不可分（§2.2），把"低对比度检出"作为卖点没有出路；应转向"判别式相位证据"（换证据形式，而非调阈值），且把可验证目标放在**假阳性抑制**上。
