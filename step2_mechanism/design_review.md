# PhASER-3D 设计评审

基于以下证据：
1. 对 `Downstream_2` 全部源码与配置的通读
2. README 记载的三组权重结果、训练日志、`validation_plan.txt`
3. `docs/` 下两份独立外部审计（deepseek《PhASER-H》、gpt《CU-PFR》）
4. 本次 Step 2 机制级验证（`report_step2_mechanism.md`，6 项实验）

---

## 0. 一句话结论

**这个模型在"工程实现"层面是扎实的，但在"科学假设"层面把一条未经检验的推论当成了前提——而实测证明这条推论不成立。**

具体地：`相位一致性是通用的边界证据` 这个命题，被用来支撑 `所以它能在低对比度下补上幅度类算子的空白`。前半句（对比度不变性）在实现中是**精确成立**的；后半句是**外推**，而它在真实噪声条件下恰好相反。整个 PFCR 的设计、Small-Tumor Head 的存在理由、以及论文的"低对比度小病灶"卖点，都建立在这条外推之上。

---

## 1. 论证链重建与逐步判定

把设计文档（代码 docstring + README §4）里的推理显式写出来，逐步对照实测：

| # | 命题 | 判定 | 实测依据 |
|---|---|---|---|
| ① | 低对比度小病灶是真正的难点 | **成立** | LiTS fold0 验证集 87 个病灶，病灶-肝实质 CNR 中位 **1.6**，低 CNR 层（<1.28）占 41%；结合预测误差，低 CNR × 小尺寸是最差象限 |
| ② | 幅度类边缘算子在低对比度下失效 | **成立** | `\|∇f\|_b / A` 在 A = 5→40 HU 上恒为常数（0.185 / 0.206 / 0.068）→ 边界响应严格正比于对比度，对比度降则线性衰减 |
| ③ | 相位一致性对对比度不变，`PC(k·x) = PC(x)` | **成立** | 无噪声下 A 从 5→40 HU，PC 图逐体素最大变化 ≤ **8.6×10⁻³**（浮点误差量级）。实现是正确的 |
| ④ | **所以 PC 能补上低对比度边界证据** | **不成立（主断点）** | σ=5 HU 时 Kovesi 阈值 **T ≈ 9.8** > 全 volume 平均 Σ_s A_s ≈ **4.9~8.5**，T/den 达 **1.17~1.98** → 因 `num ≤ den`，**PC 在 CNR ≤ 1 的每个体素上恒等于 0**。真实验证集低 CNR 层 PC 的 boundary/peri 比中位 **0.651 < 1**，劣于 `\|∇f\|` 的 0.967 |
| ⑤ | **用 PC 决定 Haar 低/中/高频路由** | **不成立（第二断点）** | route 对"肿瘤 vs 背景"的语义选择性（逐频带）≈ **10⁻⁵~10⁻⁴**（Copy2；勘误见 §3.1）；空间相对标准差仅 **10⁻³**；`\|route − 背景预算\|₁ ≈ 0.80` |
| ⑥ | **收益可归因于相位证据本身**（而非预训练/容量/训练预算） | **未检验** | 缺 A5（无 PC ranking）与 A1/A2（PCSF grad/pc）；本机现有全部 run 的 `PHASER_PFCR=1` 且 `PHASER_L_PC_BOUNDARY=1` |

**① ② ③ 成立，④ 断裂，⑤ 断裂，⑥ 未检验。** 设计的核心机制链条在第 4 步就断了。

## 2. 主断点：为什么"对比度不变"推不出"低对比度可用"

这是本次评审最重要的一条，也是最容易被混淆的一条。

### 2.1 两个设计选择的直接冲突

`PhaseCongruency` 的实现是：

```python
pc = clamp(num − T, 0) / (den + ε)
#  num = ‖Σ_s v_s‖      ← 分子与分母同量纲，商对信号幅度不变
#  den =  Σ_s A_s
#  T   = τ_total · (√(π/2) + k·√((4−π)/2))
#      = [median(A₀) / √(ln4)] · gain · (…)   ← 绝对量纲
```

- 分子/分母的比值**对对比度不变**——这是设计想要的，也确实是这么实现的。
- **但噪声阈值 `T` 是从"最高频尺度响应幅度的全 volume 中位数"估计出来的绝对量纲量。**
  - `median(A₀)` 在噪声主导时正比于噪声强度 σ；
  - `gain = Σρ_s / max ρ_s = 1.70`（把噪声能量按各尺度带宽加权）；
  - 学习到的 `k = softplus(noise_k) = 1.76`（Kovesi 默认 2.0）。

所以：**对比度下降时，信号幅度按 A 缩小，噪声幅度不缩。** `T/den` 因此单调上升。

实测（slab 几何，σ = 5 HU 固定）：

| CNR | A (HU) | T | den = Σ_s A_s | **T/den** | PC@边缘 | PC@内部 |
|---:|---:|---:|---:|---:|---:|---:|
| 0.25 | 1.25 | 9.770 | 4.930 | **1.98** | **0.0000** | 0.0000 |
| 1.00 | 5.00 | 9.770 | 5.010 | **1.95** | **0.0000** | 0.0000 |
| 4.00 | 20.0 | 9.776 | 5.577 | **1.75** | 0.0466 | 0.0000 |
| 16.0 | 80.0 | 9.865 | 8.456 | **1.17** | 0.5469 | 0.0000 |

**T/den ≥ 1 时，`clamp(num − T, 0)` 对每个体素都返回 0。**

### 2.2 这不是调参问题，是量纲问题

可以把"对比度不变性"和"绝对噪声阈值"看作两个互相抵消的设计选择：

> **PC 把对比度从信号里消掉了，却没有把对比度从噪声里消掉。**
> 于是算子的"可靠性"随对比度下降而单调恶化——而算子本身的"输出值"看起来没变。
> 这正是最容易骗过设计和评审的地方：一个在无噪声下完美满足 `PC(kx)=PC(x)` 的算子，看起来就是为低对比度而生的。

真实 CT 下的后果（验证集 87 个病灶）：

| CNR 层 | n | PC boundary/peri 比中位 | \|∇f\| 同项 | PC 胜出的病灶数 |
|---|---:|---:|---:|---:|
| low（中位 CNR 0.96） | 36 | **0.651** | 0.967 | **9 / 36** |
| mid（1.595） | 29 | 1.191 | 1.028 | 20 / 29 |
| high（2.236） | 22 | 1.678 | 1.111 | 15 / 22 |

低对比度区间 PC 的边界响应**低于**外周肝实质（比值 < 1），即与病灶边界**负相关**；且 81.8% 的低 CNR 病灶都如此。

### 2.3 一个必须承认的"部分正确"

PC 在这个实现下有一个真实优势：**它是"弃权型"的**。噪声区（PC 内部/背景）输出恒为 0，而 min-max 归一化的 `|∇f|` 在噪声区会乱响应。合成实验里 `grad_norm` 在高 CNR 下明显劣于原始 `|∇f|`，也劣于 PC。

所以准确的说法不是"PC 没用"，而是：**PC 是低灵敏度、高特异性的证据，它的收益不在"低对比度召回"，而在"减少假阳性"。** 设计文档把它当成了前者。

## 3. 第二断点：路由实际上不会用到相位证据

即使假设 PC 有效，PFCR 当前也不可能把它用起来。三条原因叠加：

### 3.1 路由输出在空间上近似常数

```
route = softmax( router( [PC, tumor_prior] ) )
router = [Conv3d(2→8), ReLU, Conv3d(8→3)]
nn.init.zeros_(router[-1].weight); nn.init.zeros_(router[-1].bias)
```

- 末层**零初始化** → 训练初期 `route = softmax(0) = (1/3, 1/3, 1/3)`；出口通道的权重必须在训练中自己长出来。
- 实测（Copy2，3 个验证集 128³ patch 平均）：

勘误（2026-10-09）：旧版本表最后一列为 2.98×10⁻⁸ / 3.31×10⁻⁹ / 3.31×10⁻⁹，源于 `s44_routes.py` 先对三带有符号差值求平均（route 和为 1，该平均恒为 0）。下表为逐频带 |Δ| 均值的复算值；结论（路由与语义近乎无关）不变，但量级是 10⁻⁴ 而非 10⁻⁸。

| 尺度 | route 形状 | 肿瘤内 [low,mid,high] | 背景内 [low,mid,high] | 空间 std | **语义选择性：逐带 \|肿瘤−背景\|** |
|---:|---|---|---|---|---:|
| 0 | 128³ | 0.3444 / 0.3269 / 0.3287 | 0.3446 / 0.3268 / 0.3286 | 1.9~4.2×10⁻⁴ | **1.67×10⁻⁴** |
| 2 | 32³ | 0.2284 / 0.4112 / 0.3603 | 0.2292 / 0.4106 / 0.3602 | 1.6×10⁻⁴~1.0×10⁻³ | **4.91×10⁻⁴** |
| 4 | 8³ | 0.3105 / 0.3576 / 0.3319 | 0.3112 / 0.3569 / 0.3319 | 7.9×10⁻⁵~9.6×10⁻⁴ | **4.78×10⁻⁴** |

**路由权重与"这个体素是不是病灶"完全无关。** 各层之间的均值确实不同（例如 scale2 = 0.228/0.411/0.360，scale0 = 0.344/0.327/0.329），说明 PFCR 学到了**每层一个固定的频带混合系数**——即"静态全图带通滤波"。

### 3.2 softmax 结构上没有"关闭"能力

三路 softmax 输出和恒为 1。这意味着 PFCR 只能**重新分配**低/中/高频的比例，无法逐体素决定"这个位置不需要任何频率增强"。在血管、肝包膜这类高 PC 的非病灶结构上，模块被迫施加某种频率组合——这正是假阳性被放大的结构原因。

### 3.3 条件输入本身是坏的

- `unet.py` 已做 `sigmoid(small_logits[:, 1:2])`，`PFCR.forward` 内又做一次 `prior.sigmoid()` → **双重 sigmoid**；而 Small-Tumor Head 用 2 类 CE 训练，正确概率应是 `softmax(logits, dim=1)[:, 1:2]`。
- 监督时机：Small-Head loss 只在 **Phase B（epoch ≥ 60）** 启用，而 **Copy2 是 epoch 48 的权重** → 在对外报告的那组结果里，**PFCR 的条件输入是随机初始化的网络输出**。

## 4. 设计合理之处（建议保留）

这些是真实的、应该肯定的工程决策，很多比同类工作做得更严谨：

| # | 设计 | 为什么合理 |
|---|---|---|
| 1 | **残差恒等初始化**：`residual_gate = 0` → PFCR 在初始化时是严格恒等映射 | 注入预训练骨干时不会破坏 VoCo 权重；`tanh(γ)·routed` 的形式让"注入强度"可学习、可归零 |
| 2 | **预训练权重的按 key/shape 选择性加载** | VoComni 是 21 类、本模型 3 类，10 个 `decoder.seg_layers.*` 形状不匹配 → 保留随机初始化而不是报错或裁剪，实测 282/292 keys（encoder 96/96） |
| 3 | **所有模块挂在环境变量开关后，可逐一消融** | `PHASER_PCSF / PFCR / LWFD / ACG / T-RAF / LA-ACG / CFF` 独立开关，且对互斥组合显式 `raise`（如 T-RAF vs LWFD、ACG vs LA-ACG）。这是可证伪设计的必要条件 |
| 4 | **grad 与 pc 两条 PCSF 路径严格配对** | 共享 `gate_sens_init`、相同的 gate 参数化与初始化，使 grad-vs-pc 成为单变量消融。代码注释还记录了"α = 0 时 `∂attention/∂PC ≡ 0`，5 步 SGD 后 `rho_raw/sigma_raw/noise_k` 梯度 ~10⁻¹⁶"的实测——这是很扎实的调试 |
| 5 | **PC ranking 用 margin-ranking，而不是回归到二值边界图** | docstring 里的理由是对的：PC 是**通用**边缘算子，把它回归到病灶边界掩膜会惩罚它在血管/包膜上的**正确**响应，破坏算子语义。用"边界响应 − 周边响应 ≥ margin"的对比式目标在概念上是正确的方向 |
| 6 | **意识到 γ=0 会掐死滤波器梯度，并给了旁路** | `pc_boundary_ranking_loss` 存在的**理由**就是为了给 log-Gabor 一条绕过 `tanh(γ)` 的梯度路径，且不在 Phase B 延迟、改用 5 epoch 短 ramp。诊断准确、修复对症 |
| 7 | **可学习 log-Gabor 参数的重参数化** | `ρ = 0.5·sigmoid(rho_raw)`、`σ = 0.05 + 0.9·sigmoid(sigma_raw)`、`k = softplus(noise_k)`，把参数约束在有效域内，比 hand-set Kovesi 常数更灵活 |
| 8 | **对 1 通道 proxy 做 FFT** | `proxy = Conv1x1(C→1)`，初始化成通道均值。FFT 成本与通道数无关，且 proxy 可学习——工程上合理 |
| 9 | **复现纪律** | `reproduce_metrics.py` 内嵌预期值与 `2e-4` 容差；README §8 明确列出 7 条"已知坑"（包括"run 目录里的 checkpoint 不是这个模型"、"pseudo dice ≠ 全卷 Dice"、"TTA 会更差"、以及一次 `oversample=1.0 + tumor oversampling` 导致全卷 Dice 崩到 0.24/0.11 的事故）。**这种级别的自我披露在研究中不常见，是真正的优点** |
| 10 | **`validation_plan.txt` 本身** | 写了可证伪命题、冻结的评测协议、预注册的停止条件（§12）。方向完全正确——问题在于它没有被执行（见 §6） |

## 6. 最应吸取的方法学教训

`validation_plan.txt` 已经把 A0–A8 的消融矩阵设计得很完整（含"预先写死的证伪条件"），但**没有执行**。而任务指标的对外陈述已经开始了。

后果是：**这次能判定 PFCR 失效，靠的不是任务指标，而是机制探针 + 1 次前向。** 因为所有已完成的 run 都开着 `PHASER_PFCR=1` 和 `PHASER_L_PC_BOUNDARY=1`，任务指标**永远无法隔离 PFCR 的贡献**——不管 Dice 涨还是跌，都无法归因。

> **教训：先跑最小对照（A0 基线 / A1 幅度域对照 / A6 完整），再谈任何模块级结论。** 一个模块是否有效，不需要等 200 epoch，需要的是"关掉它"的那一组。

## 7. 如果要救：重构方向

三条独立证据（deepseek 的 PhASER-H、gpt 的 CU-PFR、本次实测）**收敛到同一个方向**，这提高了可信度：

**把"相位一致性标量"换成"单演相位向量 + 噪声标定的可靠性 + 判别式步骤"。**

1. **证据形式**：不要用被压成 1 个标量的 PC 比值，保留单演向量 `(e, o_z, o_y, o_x)` 的**方向**（对比度不变且噪声下取平均，比幅度比值稳健得多）；用一个 t 统计量形式的可靠性 `R = E / (σ·√N_eff)` 取代启发式阈值，让证据成为"显著性"而非"比值"。
2. **判别式步骤**：学两组原子字典——病灶边界 `U_L` 与混淆结构 `U_C`（血管/包膜/噪声），证据定义为竞争比值 `‖U_Lᵀy‖ / (‖U_Lᵀy‖ + ‖U_Cᵀy‖ + ε)`。监督的**负样本必须包含血管**（Frangi 响应高的区域）以及模型在线的 FP 连通域。这是针对 §5.1-I10 和 FP 崩塌的对症修法。
3. **门控结构**：把三路 softmax 换成"同一控制器输出频带比例 + **绝对干预门** `a`"，允许逐体素关闭频率增强。
4. **监督时机**：条件输入（prior）与主模块同步从 epoch 0 起监督；损失裁剪到 `DiceCE + 边界项 + 病灶实例项` 三项，其余全部关掉，先建立可归因的基线。
5. **模型选择**：改为验证集全卷 case Dice（或病灶级 F1），移除 patch 级 pseudo Dice。

**止损条件**（沿用计划的思路）：如果修好 I1–I4 后，PC 在低 CNR 层仍无边界对比度（比值 ≤ 1），那么"相位证据对低对比度有效"这条路应该放弃，退回到"可学习 PC + 病灶级协议"的应用型定位。

## 8. 证据边界（不能声称什么）

诚实标注本次评审的证据强度：

1. **合成实验用加性白高斯噪声**。真实 CT 噪声是量子噪声（σ ∝ √I）且经插值与重采样后**空间相关**。结论的**方向**（T 是绝对量纲 → 对比度降则 PC 归零）是机制性的、稳健的；**具体阈值**需要用更真实的噪声模型复核。
2. **Copy2 只有 epoch 48 / 200**，所以"5 个注入尺度学到几乎相同的滤波器"这一条在 Copy2 上成立（跨尺度 λ 标准差 3×10⁻⁴），但在 **retrain / scratch** 上不成立（标准差 0.65~1.19，滤波器确实分化了）。因此**无法区分"结构本身坏"与"训练不够/代码版本不同"**——这两组 run 用的是不同代码版本，存在混杂。
3. **4.4 只用 3 个 patch**（受限于"肿瘤/肝/背景三区都充足的 128³ patch"这个筛选条件）。但语义选择性仅约 10⁻⁴（勘误后），相对 route 量级 0.33 可忽略。
4. **未检验判别式相位方案**（PhASER-H / CU-PFR）是否真的有效。本次只证明了**当前实现**不做它声称的事，没有证明改进方案会成功——那是 Step 3 的工作。
5. **未使用测试集**（27 例全程锁定），全部分析在 fold 0 验证集 21 例上完成。
